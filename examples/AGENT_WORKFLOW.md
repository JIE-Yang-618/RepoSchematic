# Example agent workflow

1. Run `reposchematic analyze .` in a repository.
2. Give `AI_CONTEXT.md` to a coding agent when a compact orientation is useful.
3. Use `reposchematic explain path/to/file.py` before editing an unfamiliar high-importance file.
4. Use `reposchematic deps path/to/file.py` to inspect direct internal imports and reverse dependencies.
5. Treat RepoSchematic as a navigation layer; verify changes against the real source and test suite.
